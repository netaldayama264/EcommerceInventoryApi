#E-Commerce Inventory API

A robust RESTful API built with ASP.NET Core 8 and Entity Framework Core, demonstrating complex data relationships and LINQ querying capabilities.

Features

Domain Models: Products, Categories, Shopping Carts, and Orders.

In-Memory Database: Easy to run immediately without a SQL server setup.

LINQ Filtering: Advanced querying for products based on category and price ranges.

Swagger UI: Integrated API documentation and testing interface.

How to Run

Make sure you have the .NET 8 SDK installed.

Open a terminal in the root folder of this repository.

Run dotnet restore to install dependencies.

Run dotnet run to start the server.

Navigate to http://localhost:<port>/swagger in your browser to view the API endpoints and test them out!
